# nix-config

NightHawk's NixOS + home-manager flake.

## Hosts

| Host          | Description                                                | Module                       |
| ------------- | ---------------------------------------------------------- | ---------------------------- |
| `framework`   | Framework 13, AMD Ryzen, Intel AX210 WiFi, niri + DMS + ly | `hosts/framework/default.nix` |
| `workstation` | Intel i9 11th gen + AMD RX 9070 XT, niri + DMS + ly        | `hosts/workstation/default.nix` |

Add a host: drop a directory under `hosts/<name>/` with a `default.nix`,
and add `<name> = mkHost ./hosts/<name>;` in `flake.nix`.

## Layout

```
.
├── flake.nix                         # inputs + nixosConfigurations (mkHost)
├── flake.lock
│
├── hosts/                            # one dir per machine
│   ├── framework/
│   │   ├── default.nix               #   system entrypoint
│   │   ├── hardware.nix              #   hand-written hw tweaks (btrfs, ucode)
│   │   ├── hardware-configuration.nix#   generated by nixos-generate-config
│   │   └── home.nix                  #   home-manager root for this host
│   └── workstation/
│       ├── default.nix
│       ├── disko.nix                 #   declarative GPT + BTRFS subvolumes
│       ├── hardware.nix              #   stub; replace post-install
│       └── home.nix
│
├── modules/
│   ├── nixos/                        # reusable NixOS modules (no cfg- prefix)
│   │   ├── desktop/                  #   niri, dms, ly, sound, firefox
│   │   ├── virt/                     #   docker, podman, libvirt
│   │   ├── services/                 #   avahi, syncthing
│   │   ├── kernel.nix locale.nix users.nix nix.nix gc.nix ...
│   └── home/                         # reusable home-manager modules
│       ├── desktop/niri-dms.nix
│       ├── editors/nixvim.nix
│       ├── tooling/devops.nix
│       └── core.nix linux.nix git.nix zsh.nix sops.nix ...
│
├── lib/                              # cross-cutting helpers + key material
│   ├── nix-settings.nix              #   substituters, registries, lix daemon
│   ├── nixpkgs-config.nix            #   nixpkgs config eval
│   ├── zsh-shared.nix                #   prompt + PATH helper
│   ├── firefox-policies.nix
│   ├── move-nix-store-paths-to-front.py
│   └── keys/id_rsa.pub               #   pubkeys baked into authorized_keys
│
├── secrets/                          # sops-encrypted; see .sops.yaml
└── treefmt.nix                       # `nix fmt` config (nixfmt RFC style)
```

The `r` path-record in `flake.nix` (`r.hosts`, `r.modulesNixos`,
`r.modulesHome`, `r.libs`, `r.secrets`) is passed to every module as
`specialArgs.r`. Use it for absolute paths instead of `..`-relative
imports — modules can be moved without rewriting their consumers.

## First-time bootstrap on a fresh install

1. Boot the NixOS installer, partition the disk, and run
   `nixos-generate-config --root /mnt`. Keep the generated
   `hardware-configuration.nix` — copy it into
   `hosts/framework/hardware-configuration.nix`.
2. Clone this repo into `/mnt/etc/nixos` (or `~/nix-config` after install)
   and run the initial build:
   ```
   sudo nixos-rebuild switch --flake .#framework
   ```
3. Generate your age key (for sops-nix):
   ```
   mkdir -p ~/.config/sops/age
   age-keygen -o ~/.config/sops/age/keys.txt
   chmod 600 ~/.config/sops/age/keys.txt
   age-keygen -y ~/.config/sops/age/keys.txt   # public key
   ```
   Put the public key into `.sops.yaml` under `keys:` as an anchor, add
   it to the relevant `creation_rules`, then re-encrypt existing
   secrets with:
   ```
   sops updatekeys secrets/keys/git/github.yaml
   ```

## Day-to-day

```
# rebuild & switch
sudo nixos-rebuild switch --flake .#framework

# dry-run evaluation
nix flake check
nixos-rebuild build --flake .#framework

# formatting
nix fmt
```

## Framework 13 AMD notes

- `amd_pstate=active` is enabled via `boot.kernelParams`. This is the
  recommended CPU scaling driver for Ryzen 7040 / AI 300.
- `services.fwupd.enable` is on. Run `fwupdmgr refresh && fwupdmgr update`
  to get Framework BIOS + EC updates via LVFS.
- Intel AX210 WiFi: no modprobe tweaks are needed on modern kernels.
  If you ever hit intermittent disconnects, uncomment the
  `boot.extraModprobeConfig` block in `hosts/framework/default.nix`.
- Brightness keys in Wayland: `brightnessctl` is installed system-wide
  (via `modules/nixos/desktop/niri.nix`) and DMS' niri preset already
  binds the `XF86MonBrightness*` keys to the on-screen-display.
  Membership in the `video` group lets `brightnessctl` poke the
  backlight without doas/sudo.
- Power management is handled by `power-profiles-daemon`. Do **not**
  also enable TLP.

## Workstation install

The workstation host uses [disko](https://github.com/nix-community/disko)
for declarative partitioning. To install on a fresh box:

1. Boot the NixOS minimal installer.
2. Edit `hosts/workstation/disko.nix` and replace the
   `/dev/disk/by-id/REPLACE-ME` placeholder with the `by-id` path of
   the target NVMe (`ls -l /dev/disk/by-id`).
3. Apply the disk layout *and* mount it under `/mnt`:
   ```
   sudo nix --extra-experimental-features 'nix-command flakes' \
     run github:nix-community/disko -- --mode disko --flake .#workstation
   ```
4. Generate hardware config and replace `hosts/workstation/hardware.nix`
   with the result:
   ```
   sudo nixos-generate-config --no-filesystems --root /mnt
   sudo cp /mnt/etc/nixos/hardware-configuration.nix hosts/workstation/hardware.nix
   ```
5. `sudo nixos-install --flake .#workstation`, then reboot.

## Niri / DankMaterialShell / ly

All three are wired up via flake inputs (`niri`, `dms`, `dgop`) and
gated by these modules:

- `modules/nixos/desktop/niri.nix` — niri compositor (NixOS side).
- `modules/nixos/desktop/dms.nix` — DankMaterialShell (system side, with
  `dgop` provided from upstream because the package only landed in
  nixpkgs 26.05+).
- `modules/nixos/desktop/ly.nix` — ly TUI display manager.
  No SDDM, no GDM, no Plasma 6 by default.
- `modules/home/desktop/niri-dms.nix` — niri keybinds + DMS home-manager
  integration. The DMS preset already covers most XF86 keys plus
  Mod+V (clipboard manager), so we only define the navigation /
  workspace / launcher binds explicitly here.

## Kernel

`modules/nixos/kernel.nix` exposes a single option:

```nix
nighthawk.kernel = "lts";    # or "latest" / "zen" / "hardened"
```

The framework host pins `latest` for AMD P-state improvements; the
workstation host pins `latest` because RDNA4 (RX 9070 XT) requires
Linux 6.13+.

## Editor

`modules/home/editors/nixvim.nix` is a NixVim-based Neovim setup with
LSPs for Nix / Python / Go / Rust / TypeScript / Terraform / YAML /
JSON / Bash, formatters via conform-nvim, telescope, neo-tree,
treesitter, dap, fugitive + neogit, toggleterm, and a Catppuccin Mocha
theme. It is flake-checked at eval time, so a broken plugin breaks
`nix flake check` instead of breaking your editor mid-session.

## Devops QoL

`modules/home/tooling/devops.nix` ships the day-to-day sysadmin / SRE
toolbelt: `kubectl` + `k9s` + `kubectx` + `helm` + `helmfile` +
`stern` + `argocd` + `fluxcd`, `terraform` + `terragrunt` +
`pulumi-bin` + `ansible`, `awscli2` + `gcloud` + `azure-cli`,
`docker-compose` + `dive` + `hadolint` + `trivy`, plus modern shell
QoL: `direnv` + `nix-direnv`, `atuin`, `zoxide`, `fzf`, `ripgrep`,
`fd`, `jq`, `yq-go`, `just`, `lazygit`.

## SOPS

See `.sops.yaml` for age-key groups. The home-manager module
`modules/home/sops.nix` decrypts the GitHub SSH key and token at
login using `~/.config/sops/age/keys.txt`.

## CI

`.github/workflows/check.yml` runs `nix flake check` on every push
and pull request so broken evals never reach `main`.
